上から順になぞるだけ

SV の60分が律速。採水から戻ったら一番先に仕掛ける。
COD が無いぶん、日常よりずっと軽い。ろ過も自分ではやらない（脱水担当がやってくれる）。
値が出たら、その場でタブレットに入れる。

待ちのある工程は茶色。
タイマーを押すのは SV（30分・60分）と遠心（20分）だけ。
バス・乾燥機・デシケーターは「◯分以上」なので押さない＝時刻で動く。

8:30
前日分の計量 → 次回分のろ紙・磁皿を用意（1枚ずつ風袋を測ってタブレットへ）→ 一服
乾燥機に入っているものは、深川の分だけとは限らない。
納内・音江・多度志で作業してきた人が、持ち帰ったケーキやろ液を自分で乾燥機に入れて帰る。それを翌朝最初に分析に入る人がまとめて測る。
枚数は 水質分析 → 分析準備 の表で引く。

9:30 — 採水
9:30
AT-3 / AT-4 / C / D / E。曝気槽が主役で、C・D・E は透視度と残塩のぶん。
生汚泥は採らない。点検当番の人が採って、そのままウォーターバスに入れてくれる。
簡易は水温を測らない。持ち帰ってから困ることはない
2
SV を仕掛ける
30分 ＋ さらに 30分
AT-3・AT-4 の2本。戻ったら一番先にこれ。
▶ タイマー 30分 を押す
30分で鳴ったら読む。読んだら、もう一度 30分 を押す（帳票の括弧の中が60分値）。
3
遠心を回す
20分
AT-3・AT-4 の水を 100mL 量って遠心へ。4本×2台なので同時に回せる。
▶ タイマー 20分 を押す
この20分の間にやること
  • pH … AT-3 / AT-4
  • 透視度 … C / D / E
  • 残留塩素 … E
  • DO（MLDO）… AT-3 / AT-4。15分もかからない
4
遠心が上がる → 磁皿へ
AT-3・AT-4 を磁皿に移してウォーターバスへ。
バスに入れたら、そこで手は離れる。2時間以上入っていればいい。
早く入れるほど早く終わる。10:55 は 12:55 の乾燥機に間に合う最低ライン。
バスは穴ごとに定位置のラベルが貼ってある。どの磁皿をどの穴に置くかが決まっている
5
SV 60分を読む
