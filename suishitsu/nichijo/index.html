メニュー 日常分析

上から順になぞるだけ

待ちのある工程は茶色。待っている間に何をやるかは、その枠の中に書いてある。
12:55 に乾燥機へ入れて 15:00 に出す——ここから全部の時刻が決まる。

値が出たら、その場でタブレットに入れる。紙に書き写す作業はない。
メモを取るのは採水したときの水温くらい。

採水は 9:30 から。戻ってすぐ SV を仕掛ける。
SV の60分がそのまま律速。早い人は 11:00 に終わっている。遅くとも 11:40。
バス・乾燥機・SV は仕掛けた時点で手が離れる。早く入れるほど早く終わる。
手が塞がるのは COD滴定 と ろ過 の2つだけ。

待ちのある工程は、その場でタイマーを押す。機器にタイマーが付いていて、アラームで呼び戻してくれる。
時刻を覚えておく必要はない。押したら次の作業に移っていい。

タイマーを押すのは「ちょうど◯分」で戻る工程だけ。
・押す … SV（30分・60分）／ COD加熱（30分）／ 遠心（20分）
・押さない … ウォーターバス ／ 乾燥機 ／ デシケーター（どれも「◯分以上」で、過ぎても構わない）

戻ったら
2
SV を仕掛ける
30分 ＋ さらに 30分
AT-3・AT-4 の2本。採水から戻ったら一番先にこれ。一番長い待ちなので最初に走らせる。
  • 30分後に1回読む
  • 60分後にもう1回読む（帳票の括弧の中が60分値）
▶ タイマー 30分 を押す
仕掛けたら放置ではない。30分で鳴ったらいったん戻る。読んだら、もう一度 30分 を押す。
3
透視度を測る
A / B / C / D / E の5か所。待ちなし。
ここで COD の検水量が5本ぶん全部決まる。目安は透視度 × 2。
上限は 100mL なので、透視度50以上は頭打ち。
迷ったら2本立てていい — 外した時は再加熱30分。保険は滴定1回ぶん。バスは12穴で6本しか使わない
4
COD を仕込んで加熱
30分
三角フラスコ 6本（A・B・C・D・E ＋ BL）。
  • 検水を量ってフラスコへ。足りない分は蒸留水で100mLにメスアップ
  • BL は蒸留水 100mL
  • 硫酸(1+2) 10mL ＋ 過マンガン酸カリウム 10mL
  • ウォーターバスで 30分 … タイマー30分を押す
この30分の間にやること
  • 遠心を回す（20分） — 4本×2台で AT-3・AT-4 を同時に。ここもタイマー
  • pH … A / B / AT-3 / AT-4 / C / D / E / RS の 8か所
  • 残留塩素 … D と E
色は バスに入れる前も、上げた時も 紫のまま。加熱しても変わらないので、色で進み具合は分からない（だからタイマー）。
上げた時に紫が消えていたら失敗。過マンガン酸が足りなかった＝汚れが濃すぎる。検水を減らしてやり直す（再加熱30分）
5
SV 30分を読む
AT-3・AT-4。読んだらもう一度タイマー 30分 を押す。
6
遠心が上がる → 磁皿へ
MLSS 3・MLSS 4 を磁皿に移してウォーターバスへ。
バスに入れたら、そこで手は離れる。あとは時間が経つだけ。2時間以上入っていればいい。
早く入れるほど早く終わる。10:55 は 12:55 の乾燥機に間に合う最低ライン。
バスは穴ごとに定位置のラベルが貼ってある。どの磁皿をどの穴に置くかが決まっている
7
COD を滴定する
色が動くのはここから。
紫（加熱が終わったフラスコ）
→ シュウ酸ナトリウム 10mL を入れる → 透明
→ 過マンガン酸カリウムで滴下 → うすい紫（ピンク）が出たら止める。そこで目盛りを読む。
  • 6本ぶん繰り返す。ここは手が塞がる
  • 滴定値が 3.5〜5.5 mL に入っていれば OK
  • ビュレットは2セットあるので2人なら分担できる
COD[mg/L] ＝（a − BL）× f × 200 ÷ 検水
8
ろ過（ろ紙のSS）
A / B / C / D / E の 5枚（脱水がある日は ろ液 で6枚）。
  • ろ紙をセット → ファンネル → クランプ
  • 先に蒸留水を通してから試料を通す
  • ろ紙に色が付くまで
検水量は固定ではない。その日の水で変わる。引けない時は量を減らす。
参考（水が綺麗な日）… A 100 / B 100 / C 400 / D 400 / E 1,000
装置は1セット。1枚ずつ差し替える直列作業。ここが遅れると乾燥機に間に合わない
9
MLDO
15分
AT-3・AT-4。電極ではなく滴定（ウィンクラー法）。すぐ終わる。隙間に入れられる。
  • 試薬3本 … 硫酸マンガン / アルカリ性ヨウ化カリウム / 硫酸銅・スルファミン酸
  • チオ硫酸で滴定 → 薄黄色でデンプン → 青くなる → 青が消えて終点
瓶が系列で固定されている。DO3＝AT-3（容量 99.0）／DO4＝AT-4（容量 98.0）。
容量がそのまま計算に入るので瓶の番号を必ず確認。

タブレットの並び

シートの並びは参考まで（全12ページ）。
